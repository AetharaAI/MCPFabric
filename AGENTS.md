## Role
This repository is the MCPFabric frontend.

Primary agent responsibility on this VM:
- keep `mcpfabric.space` usable as the operator and admin surface for Fabric
- expose real backend capabilities before inventing frontend-only behavior
- keep production deploys explicit, reversible, and documented

## Operating Rules
- Frontend changes come first unless the frontend exposes a genuine backend mismatch.
- Do not change backend behavior just to satisfy a frontend assumption.
- Browser-only failures should be checked for CORS/preflight before auth or payload changes.
- Do not commit secrets.
- Treat `.env` as runtime input, not documentation.
- Publish only from a verified production build.

## Standard Workflow On This VM
1. Inspect production reality and current docs.
2. Change frontend source.
3. Update canonical docs.
4. Build with `npm run build`.
5. Publish with `sudo rsync -a --delete dist/ /var/www/mcpfabric/`.
6. Verify the new bundle on `https://mcpfabric.space`.
7. Commit and push from a clean branch/worktree, not from secret- or build-dirty state.
